# 🎙️ AI Voice Assistant (Text + Speech)

An AI-powered voice assistant that enables seamless interaction through both text and speech. This application accepts user input via typing or voice and generates intelligent responses in both text and audio formats using modern AI models.

---

## 🌐 Live Demo

Try the app instantly — no setup required:

🔗 **Live App: https://huggingface.co/spaces/Navneetpal09/voice-assistant

✨ What you can try:

* 🎤 Ask questions using voice
* ⌨️ Type queries
* 🔊 Listen to AI-generated responses

## ✨ Features

* 🎤 Voice Input (Microphone support)
* ⌨️ Text Input
* 🤖 AI-generated responses
* 🔊 Text-to-Speech output
* ⚡ Interactive UI using Gradio

## 📦 Installation

1. Clone the repository:

```
git clone https://github.com/YOUR_USERNAME/voice-assistant.git
cd voice-assistant
```

2. Install dependencies:

```
pip install -r requirements.txt
```

3. Set your Hugging Face token:

```
export HF_TOKEN=your_token_here
```

---

## ▶️ Run the App

```
python app.py
```

---

## 🔐 Security Note

For security reasons, API tokens are not included in the code.
Please set your Hugging Face token as an environment variable before running the application.
